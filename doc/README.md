## 阅读顺序建议

1. 先读 `开发计划.md` §1-§5，明确范围与模块。
2. 再读 `数据库设计.md` §3（DDL）与 `API设计.md` §1（约定），作为编码基线。
3. 按 `开发计划.md` §11 的里程碑逐阶段实施，每阶段用 §15 验收标准自测。
4. 文档与实现不一致时，先更新文档再改代码（迁移只增不改）。
