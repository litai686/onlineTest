## 与计划文档的差异

1. **公式编辑器**：v1 采用「多行文本 + MathLive 浮层插入 `$latex$` + KaTeX 预览」；计划中的 `contenteditable` 内联公式芯片列为 P1（组件接口已隔离，替换时无需改页面）。
2. **迁移**：当前全部使用 GORM `AutoMigrate` + `extraDDL`（组合/部分索引）。`migrations/*.sql` 仅在未来做删列/改约束时引入。
3. **扫描版 PDF**：遵循计划，提示上传页面截图；未引入 pdfium。
4. **P1 未做**：登录限流/锁定、审计日志、强制到点交卷、学生文件直链以外的图片缩略图、AI 视觉探测、班级统计。
5. **公式等价**：仅填空题在 LaTeX 规范化后仍不等时调用 AI 判定；解答题由 AI 阅卷流程统一处理。

## 关键文件

```

internal/httpapi/                  路由、中间件、Handler
web/js/components/math-input.js    MathLive 公式输入
web/js/components/math-render.js   KaTeX 渲染
```
